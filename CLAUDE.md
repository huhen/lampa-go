# lampa-go — правила проекта

Go-сервер для Lampa: spec — `docs/superpowers/specs/`, документация — `docs/`, план — `docs/superpowers/plans/`.

## Правила рабочего процесса

- **Завершение реализации** (задачи, итерации, ветки) → **Push + Pull Request** в `main`. Локальный merge не используем.
- **Замеченные недочёты и бэклог** → оформляем как **GitHub issues** (не держим в переписке): краткое описание, где в коде, почему это проблема/что нужно сделать.
- Язык: документация и issues — русский, технические термины на английском; код и комментарии — только английский.
